# SPACE Y 80개 냉각채널 템플릿–`h_l` 통합 파이프라인

## 1. 목적과 책임 경계

`cooling_channel_pipeline.py`는 80개 `(w_ref,b,h)` 참고 템플릿을 실제 평균 채널
배치반경, 제조 제약, 냉각유량·물성과 연결한다. 기존
`solve_cooling_channel_candidates()`와 `evaluate_rectangular_cooling_hl()`을
재사용하며 Gnielinski, Colebrook 또는 Darcy–Weisbach 식을 다시 구현하지 않는다.

결과는 형상·국소 `h_l`·마찰 압력손실 구배와 예비 상대 비교다. CFD, IPA 상태
marching, 전체 압력손실 적분, 가스 측 열전달, 벽온도, 비등·상변화, 구조 검토와
최종 설계 선택은 포함하지 않는다.

## 2. 데이터 흐름

1. `generate_reference_width_templates()`로 80개 템플릿을 생성한다.
2. 실제 또는 명시적 합성 목 평균 채널 배치반경에서 각 템플릿의 `N_ideal`을 계산한다.
3. 각 템플릿에 대응하는 서로 다른 floor/ceil 양의 정수 `N`만 생성한다.
4. `(N,b,h)`가 같은 실제 형상은 한 번만 계산하고 모든 원래 template ID와 목표 폭을
   보존한다.
5. 각 station에서 `w(x)`, 전체 `A_f(x)`, `D_h(x)`와 제조 제약을 검사한다.
6. 유효 형상만 기존 단일 후보 sweep 코어로 전달한다.
7. 모든 고유 후보를 공통 station에서 기존 추천 계층으로 비교한다.

N 후보들의 합집합과 모든 `b,h`의 Cartesian product를 다시 만들지 않는다. 따라서 한
템플릿에 대응하지 않는 임의 형상 조합은 생성되지 않는다.

## 3. 단계별 입력 상태

| 단계 | 제공 입력 | 처리 | 상태 |
|---|---|---|---|
| `TEMPLATE_ONLY` | template grid | 80개 템플릿만 생성 | `INPUT_U` |
| `GEOMETRY_ONLY` | 반경 또는 반경+제조 제약 | 정수 N과 station 형상 생성, `h_l` 미계산 | `INPUT_U` |
| `FULL_CANDIDATE_EVALUATION` | 형상·제조·유량·물성·모델 | 유효 고유 형상 계산 및 상대 비교 | `MODEL_U` 또는 `OUTSIDE` |
| `FAILED` | 형식·근거 불충분 또는 범위 이탈 | 결과 생성 중단, 원인 보존 | `INPUT_U`/`OUTSIDE` |

미확정 값을 기본값으로 채우지 않는다. 실제 screening은
`input_evidence_complete=true`, `TEAM_GEOMETRY_EVIDENCE`,
`TEAM_APPROVED_MANUFACTURING_CONSTRAINTS`와 exact 2-propanol
`CAS 67-63-0` 식별을 요구한다. 이 게이트도 물리 검증 완료나 안전 승인을 의미하지
않는다.

## 5. 식별자와 중복 제거

- `template_id`: 목표 `(w_ref,b,h)`를 나타낸다.
- `geometry_candidate_id`: 실제 `(N,b,h)`와 공통 반경 프로파일을 나타낸다.
- `template_origins`: 한 실제 형상을 만든 모든 template ID, 목표 폭, 실제 목 폭과
  차이를 기록한다.

80개 템플릿에서 각 2개 정수 N을 검토하면 raw 연결은 최대 약 160개다. N이 이미
정수이거나 여러 템플릿이 같은 `(N,b,h)`를 만들면 수가 줄어든다. 중복은 계산만 한
번 수행하고 provenance는 삭제하지 않는다.

## 6. 합성 전 구간 검산

합성 fixture는 80개 템플릿, 세 개 합성 반경 station, 합성 제조 제약, 합성 유량과
일정 물성을 사용한다. 실제 IPA나 실제 노즐 입력이 아니다.

- template: 80
- raw template–N 연결: 160
- 고유 실제 형상: 160
- 합성 기하 제약 통과: 156
- 계산 station: `156 × 3 = 468`
- 최고 목 `h_l` 태그 후보: 1
- 최소 목 마찰 구배 태그 후보: 1
- 비지배 후보: 58
- 팀 Re 예비 권고를 만족한 합성 후보: 6
- 모델 경고가 있는 합성 후보: 156

경고 후보 수가 많은 이유는 `Re<10000` 천이 주의도 경고로 기록하기 때문이다. 이
결과로 특정 형상을 실제 설계에 추천하거나 제외하지 않는다. `validated_engine_prediction`,
`safety_approval`, `final_design_selection`은 모두 `false`, V01–V12는 `NOT_RUN`이다.

## 7. 실제 연결에 필요한 외부 입력

- 형상팀: 실제 station 좌표, throat ID, `r_m(x)` 정의·값·출처
- 제작·구조팀: 승인 폭 범위, 최소 리브, 허용 높이, 등가 모래거칠기
- 시스템팀: 실제 재생냉각 통과유량과 분기 경계
- IPA 물성팀: station별 `rho,mu,cp,k`, 출처·판본·유효범위와 단상 근거
- 열해석팀: 열적 경계조건, 완전발달 조건과 각 상관식 적용 근거
- 통합팀: 공통 비교 station, 전체 압력예산·벽온도·상변화·구조 제약

이 자료가 없으면 readiness 입력은 80개 템플릿만 반환하고 `INPUT_U`를 유지한다.
