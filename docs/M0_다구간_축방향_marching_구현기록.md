# M0 단일 냉각 경로 다구간 축방향 marching 구현 기록

기준일: 2026-10-31

## 결과와 사용 상태

기존 `solve_coupled_single_segment`를 구간 계산기로 재사용하고, 한 개의 처방 질량유량 냉각 경로를 명시된 냉각 진행 순서로 연결하는 marching 계층을 구현했다. 이 계층은 비설계 인터페이스 및 산술 검산만 허용한다. 합성 실행이 수렴해도 출력은 `MODEL_U`, V01–V12는 `NOT_RUN`, `validated_engine_prediction`은 `false`다.

실제 SPACE Y 형상, 냉각 입구조건, 유체 물성, 복사 입력 또는 안전 허용값은 추가하지 않았다.

## 좌표와 유동 순서

입력은 서로 다른 두 순서를 명시해야 한다.

- `gas_axial_order_segment_ids`: 가스 축 좌표가 엄격히 증가하는 순서
- `coolant_flow_order_segment_ids`: 냉각유체가 실제로 통과하는 순서

`coolant_flow_direction`은 `INCREASING_GAS_AXIAL_COORDINATE` 또는 `DECREASING_GAS_AXIAL_COORDINATE`여야 한다. 선언과 좌표 순서가 일치하지 않으면 `INPUT_U`다. 합성 예제는 `SYN-X2 → SYN-X1 → SYN-X0`의 감소 좌표 역류를 사용하지만 실제 엔진의 유동 배치를 뜻하지 않는다.

각 구간의 CEA 연결은 다음 정보를 요구한다.

- `method: EXPLICIT_NO_INTERPOLATION`
- 매핑 출처
- CEA 실행 산출물 경로와 SHA-256
- chamber station index, local station index, transport basis

어떤 구간에서도 인접 CEA station의 공간 보간이나 물성 외삽을 하지 않는다. 입력 station이 CEA 산출물 또는 Bartz 적용 조건 밖이면 단일 구간 솔버의 `OUTSIDE`가 전체 경로에 전파된다.

## 상태 전달과 보존식

구간 `i`의 출구 절대압, 온도 및 엔탈피를 냉각 진행 순서의 구간 `i+1` 입구로 전달한다. 후속 단일 구간 호출에는 출구 엔탈피를 별도 전달하고, 물성표에서 재구성된 온도와의 일관성을 확인한다.

처방 단일 경로이고 분기·유입·유출이 없으므로 모든 구간에서 동일 질량유량을 사용한다. 현재 질량 잔차는 이 경계조건의 연속식 항등식으로 0이며, 병렬 분배를 푼 결과가 아니다.

전체 경로 에너지 잔차는 다음과 같이 계산한다.

\[
R_E=\sum_i \dot Q_{c,i}-\dot m\left(h_{out,path}-h_{in,path}\right).
\]

추가로 다음을 기록한다.

- 구간별 냉각 엔탈피 잔차와 벽 에너지 잔차
- 인접 구간 엔탈피·압력·온도 연속 잔차
- 구간 압력손실 합과 경로 입출구 압력차의 잔차
- 경로 전체 최소 절대압, 최대 벽온, 총열량 및 최종 출구온도

## 상태 전파

구간 솔버가 `INPUT_U`, `OUTSIDE` 또는 `NUM_U`를 반환하면 다음과 같이 처리한다.

1. 실패 구간까지의 실행 기록을 보존한다.
2. 이후 냉각 순서의 구간은 실행하지 않는다.
3. 이후 구간을 `BLOCKED_BY_UPSTREAM`으로 표시하고 실패 상태를 전파한다.
4. 전체 Y01–Y05 값은 `null`로 두고 같은 상태를 부여한다.

정상 수렴한 구간도 실제 물리 검증이 없으므로 `MODEL_U`다.

## 합성 검산 결과

3구간 역류 합성 문제에서 다음 수치 결과를 얻었다. 아래 수치는 실제 엔진 결과가 아니다.

- 냉각 진행 순서: `SYN-X2 → SYN-X1 → SYN-X0`
- 총 합성 열유입: 약 `115443.6438 W`
- 경계 엔탈피 상승률: 약 `115443.6438 W`
- 전체 에너지 잔차: 약 `2.91e-11 W`
- 구간 냉각 에너지 잔차 최대값: 약 `3.64e-11 W`
- 구간 벽 에너지 잔차 최대값: 약 `2.18e-11 W`
- 엔탈피·압력 연속 잔차 최대값: `0`
- 질량 잔차 최대값: `0`
- 압력손실 합산 잔차: `0 Pa`

자동 시험은 단일 구간 모델과의 일치, 역류 순서, 전체 보존식, 좌표 방향 오류, CEA 매핑 출처 누락, CEA 적용 이탈의 후속 차단, 구간 미수렴의 `NUM_U` 전파와 파일/Schema 경로를 확인한다.

## 수치·물리적 한계

- 냉각 물성은 합성 온도표이며 압력 의존성이 없다.
- 공급된 합성 단상 영역은 실제 포화선 또는 상평형 모델이 아니다.
- 벽면비등, ONB, CHF, dryout, 2상 유동은 `NOT_EVALUATED`다.
- 가속 압력손실은 포함하지 않는다.
- 축방향 벽 전도와 구간 사이 고체 열결합은 없다.
- 병렬 채널, 매니폴드 및 유량 재분배는 없다.
- CEA station과 실제 노즐 좌표의 물리적 매핑은 검증되지 않았다.
- 복사 입력은 구간별 명시적 합성 순열률이며 복사 모델 검증이 아니다.
- 공간 분할 독립성 V08, 불확실성, 허용조건 및 실험 대조는 수행하지 않았다.
