# SPACE Y M0 정상 단일경로 구현 기록

작성일: 2026-10-31
기준: `SPACE_Y_재생냉각_모델선정과_PDR판단기준_v2_1.md`와 `SPACE_Y_M0_입력_인터페이스_검증기록.md`

이 문서는 M0 계산 코어의 첫 구현 범위와 검산 결과를 기록한다. 합성 입력의 계산값은 실제 SPACE Y 설계 파라미터, 후보 성능 또는 안전 허용값이 아니다.

## 1. 구현 범위

이번 증분은 다음 조건만 지원한다.

- 정상상태
- 지정 냉각유량 `PRESCRIBED_MASS_FLOW`
- 한 개의 직렬 냉각 경로
- 냉각 진행 순서로 나열한 1D 구간
- 구간별로 외부 GAS 모듈이 제공한 `h_g`, `T_aw`, 순복사 열전달률
- 가스 가열면적, 냉각 젖은 면적, 유동 단면을 분리한 열저항
- 압력 범위가 명시된 온도 기반 단상 물성표의 선형 보간
- I18에서 제공한 적용영역 안에서만 사용하는 문서 표시형 Gnielinski 관계
- Darcy형 Colebrook 마찰계수
- Darcy–Weisbach 마찰손실과 명시적 국부손실계수

구간별 정상 열전달률은 다음 연결식으로 계산한다.

```text
R_g = 1 / (h_g A_g)
R_c = 1 / (eta_o h_c A_c)
Q_total = (T_aw - T_bulk + Q_rad,net R_g) / (R_g + R_wall + R_c)
Q_conv = Q_total - Q_rad,net
```

이 식은 `Q_total = Q_conv + Q_rad,net`과 정상 벽 에너지 수지를 동시에 만족시킨다. 냉각 출구 상태는 `h_out = h_in + Q_total / m_dot`으로 갱신하고, 같은 반복에서 평균 국소 상태의 물성과 압손을 다시 계산한다.

## 2. 중단 규칙

| 조건 | 반환 상태 | 처리 |
|---|---|---|
| 필수 값·출처·복사 정의 누락 | `INPUT_U` | QoI 값을 `null`로 반환 |
| 물성표 온도/압력 범위 이탈 | `OUTSIDE` | 외삽 없이 즉시 중단 |
| Re/Pr/형상/발달 조건 이탈 | `OUTSIDE` | 대체 상관식을 자동 적용하지 않음 |
| 구간 반복 또는 에너지 잔차 실패 | `NUM_U` | 진단만 반환하고 정상 결과로 채택하지 않음 |
| 압력 구동·병렬·과도 등 미구현 문제 | `MODEL_U` | 지정 유량 단일경로로 몰래 근사하지 않음 |
| 합성 검산이 수렴 | `MODEL_U` | 수치는 구현 검산용으로만 유지 |

입력 파일이 `NON_DESIGN_VERIFICATION`이 아니라면 `input_evidence_complete=true`를 명시해야 한다. 이 게이트가 실제 출처의 적합성을 자동 입증하는 것은 아니며, 무근거 실행을 막는 최소 보호장치다.

## 3. 합성 검산

[합성 입력](../examples/m0_synthetic_single_path.json)은 실제 유체가 아닌 선형 물성표와 2개 구간을 사용한다. 상관식 범위도 실제 채택 범위가 아니라 중단 로직을 시험하기 위한 합성 범위다.

[실행 증거](../artifacts/m0/m0_synthetic_single_path_run.json)의 결과:

- 두 구간 반복: 19회, 18회
- 최대 구간 에너지 잔차: 약 `1.82e-12 W`
- 벽 에너지 잔차: `0 W`
- 모든 제공 적용범위 검사: 통과
- QoI 산출 상태: 모두 `MODEL_U`
- `validated_engine_prediction`: `false`
- V01–V12: `NOT_RUN`

합성 사례의 벽온·압손·열량·출구온도 숫자는 코드 연결과 부호, 단위, 잔차를 검산하기 위한 값이다. 실제 후보 비교에 사용하지 않는다.

## 4. 자동 테스트

전체 18개 테스트가 통과했다. M0 관련 검사는 다음을 포함한다.

- 정상 단일경로 수렴과 양의 압손/온도상승
- Gnielinski 적용범위 이탈 시 QoI 무효화
- 물성표 범위 밖 상태의 외삽 금지
- 압력 구동 모드의 자동 근사 금지
- 필수 입력 누락 시 `INPUT_U`
- 엔탈피 기준값이 음수일 수 있음을 허용

## 5. 미구현·미검증

- 실제 IPA 조성 및 `p,T,h` 의존 물성 데이터 연결
- 기존 `m0.py` 다구간 반복 내부의 Bartz 보정 갱신과 CEA station 공간 매핑. 별도 단일 구간 결합은 `m0_coupled.py`에서 구현됨
- 압력 구동 유량 해
- 매니폴드와 병렬 채널 유량 분배
- 리브/핀 다구역 전도와 축방향 전도
- 벽·유체 축열과 시동/종료 과도
- 벽면 비등, 벌크 2상, CHF/드라이아웃
- 가속 압력항과 밀도 변화가 큰 압손 모델
- 공간분할 N/2N/4N 및 시간분할 검증
- 입력/상관식/수치/실험 불확실성 전파
- 실제 허용조건과 목적별 PDR 판단
- 독립 시험자료 및 RPA와의 동조건 대조

따라서 이 구현은 M0 solver 구조의 첫 실행 가능한 증분이며, 실제 엔진 예측이나 안전 판단 도구로 승인된 상태가 아니다.

## 6. 실행

```powershell
.\.venv\Scripts\space-y.exe m0-run `
  examples\m0_synthetic_single_path.json `
  --schema schemas\SPACE_Y_M0_run.schema.json `
  --output artifacts\m0\m0_synthetic_single_path_run.json
```
