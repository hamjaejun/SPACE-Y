# M0 수치 검증 강화 및 실제 입력 연동 준비

기준일: 2026-10-31

## 1. 범위와 상태

이번 단계는 새 물리 모델을 추가하지 않고 다음 두 항목을 분리해 진행했다.

1. 기존 단일·다구간 M0의 보존식, 상태 전달 및 반복 수렴에 대한 합성 수치 검증
2. 실제 IPA 물성과 노즐 좌표–CEA station 자료를 받기 위한 입력 준비 상태 명세

합성 검산은 소프트웨어 검증 증거일 뿐 실제 SPACE Y 예측이나 물리 검증이 아니다. 실행 결과는 `MODEL_U`, 실제 입력 준비 상태는 `INPUT_U`, V01–V12는 `NOT_RUN`이다.

## 2. N/2N/4N 공간분할 시험

### 2.1 시험 구성

고정된 합성 길이·면적·복사 열률을 각각 1, 2, 4개의 동일 셀로 나눴다. 냉각유체는 감소 가스 축 좌표 방향으로 진행한다. 모든 셀은 다음 정책을 따른다.

- `EXPLICIT_PER_CELL_NO_INTERPOLATION`
- 각 셀에 CEA artifact, station index, transport basis와 매핑 출처를 명시
- 실제 station 사이의 좌표·면적비 보간 없음
- 검산용 상수 가스장을 만들기 위해 모든 셀이 동일한 명시 station을 참조
- 길이, 가스 가열면적, 냉각 젖은면적, 벽 전도면적과 합성 순복사를 셀 분율로 분할
- 국부손실 `K`는 분할 규칙이 별도로 필요하므로 이 시험에서는 명시적으로 0

이는 실제 노즐의 축방향 가스 분포가 아니라 분할 및 상태 전달 구현만 검산하는 manufactured fixture다.

### 2.2 정규화

전체 열수지의 정규화 잔차는 다음과 같다.

\[
r_E=\frac{|\sum_i\dot Q_i-\dot m(h_{out}-h_{in})|}
{\max(|\sum_i\dot Q_i|,Q_{floor})}.
\]

구간 냉각·벽 에너지 잔차도 전체 열량으로 정규화한다. 압력손실 합산 잔차는 전체 압력손실로, 질량 잔차는 경로 질량유량으로 정규화한다. 분모 floor는 0 나눗셈 방지용 수치 설정이며 물리 허용값이 아니다.

### 2.3 결과

| 격자 | 셀 수 | 전체 에너지 정규화 잔차 | 구간 냉각 잔차 최대/총열 | 구간 벽 잔차 최대/총열 | 압력·질량 정규화 잔차 |
|---|---:|---:|---:|---:|---:|
| N | 1 | 3.96e-16 | 3.96e-16 | 1.19e-15 | 0 |
| 2N | 2 | 1.98e-16 | 1.98e-16 | 2.97e-16 | 0 |
| 4N | 4 | 0 | 1.99e-16 | 2.49e-16 | 0 |

주요 출력의 fine grid 대비 상대 변화는 다음과 같다.

| QoI | N→2N | 2N→4N | 관찰 차수 |
|---|---:|---:|---:|
| Y01 최대 벽온 | 0.4911% | 0.2154% | 1.186 |
| Y02 압력손실 | 0.01069% | 0.1949% | -4.191 |
| Y03 총열량 | 0.1559% | 0.5279% | -1.752 |
| Y04 최소 절대압 | 6.57e-6% | 1.20e-4% | -4.191 |
| Y05 출구온도 | 0.02821% | 0.09512% | -1.752 |

보존식 잔차는 매우 작지만 Y02–Y05의 연속 refinement 차이가 감소하지 않아 세 격자가 asymptotic regime에 있다는 증거는 없다. 따라서 결과는 `NOT_ESTABLISHED`, `RECORDED_NO_ENGINE_ERROR_BUDGET`으로 기록한다. 4N을 정답으로 취급하지 않으며 V08을 `PASS`로 바꾸지 않는다.

## 3. 실제 IPA 물성 입력 준비

### 3.1 확인한 후보 출처

- [NIST Chemistry WebBook의 2-propanol, CAS 67-63-0](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67630&Mask=4)은 정상비점·임계점·증발엔탈피 등 phase-change 자료를 제공한다.
- [NIST WebBook Antoine 계수](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67630&Plot=on&Type=ANTOINE&Units=CAL)는 329.92–362.41 K와 395.1–508.24 K의 개별 유효범위를 제시한다. 범위 사이를 임의 연결하거나 압축액 물성 모델로 전용하지 않는다.
- [AIChE DIPPR 801](https://www.aiche.org/dippr/events-products/801-database/thermophysical-properties)은 액체 비열·밀도·열전도도·점도·증기압·증발열 항목과 권고값/정확도 메타데이터를 제공하는 데이터베이스다. [공개 compound list](https://www.aiche.org/sites/default/files/docs/embedded-pdf/DIPPR-Compound-List-2011.pdf)에는 isopropanol이 포함되지만, 실제 상관식 계수·판본·유효범위는 현재 저장소에 없고 라이선스 확인도 필요하다.
- [NIST REFPROP](https://www.nist.gov/programs-projects/reference-fluid-thermodynamic-and-transport-properties-database-refprop)은 순수유체·혼합물의 열역학/수송물성을 제공하는 후보 도구다. 현재 확보 자료만으로 사용 중인 판본에 정확한 2-propanol 모델이 포함되는지, 그 식과 유효범위가 무엇인지 확정하지 않았다.

WebBook의 phase-change 또는 Antoine 자료만으로 M0에 필요한 `rho`, `mu`, `cp`, `k`, `h(p,T)`, `T(p,h)` 전체를 만들 수 없다. DIPPR/REFPROP 또는 별도 평가 데이터가 확보되기 전에는 실제 IPA 모델을 `INPUT_U`로 유지한다.

### 3.2 필수 데이터

실제 물성 모델은 최소한 다음을 가져야 한다.

- 화학 식별자, 순도, 수분 및 첨가제와 그 출처
- 공급자/데이터셋/판본, 원 식 또는 데이터 참고문헌
- 각 물성의 유효 온도·절대압·상 영역과 불확실성
- `h(p,T)`, `T(p,h)`, `rho(p,T)`, `mu(p,T)`, `cp(p,T)`, `k(p,T)`
- 엔탈피 기준상태의 온도·압력·상·기준값
- 다른 데이터셋과 결합할 때의 명시적 엔탈피 offset
- `p_sat(T)`, `T_sat(p)`, 포화 액/증기 엔탈피와 `phase_or_quality(p,h)`
- 임계영역·과냉액·준안정 상태의 처리 규칙
- 벽면비등 판단에 필요한 별도 표면/열유속/상관식 근거

엔탈피 영점은 임의일 수 있지만 동일 계산 경로에서는 한 기준을 일관되게 사용해야 한다. 서로 다른 기준의 절대 엔탈피를 offset 확인 없이 연결하지 않는다.

## 4. 실제 노즐 좌표–CEA station 인터페이스

실제 매핑 레코드는 최소한 다음을 요구한다.

- 노즐 geometry version과 원본 SHA-256
- 축 좌표 원점·방향·단위, throat 위치
- 구간 경계와 대표 좌표 정의
- 원본 contour에서 계산한 `A(x)/At` 및 출처
- CEA case 정의와 artifact SHA-256
- station index, Mach/area-ratio station 의미, frozen/equilibrium transport basis
- 동일 면적비에서 subsonic/throat/supersonic branch 구별
- 구간–station 직접 대응 근거와 검토 상태

정확한 station이 없는 구간은 `INPUT_U`다. station array 범위 밖은 `OUTSIDE`다. 최근접 좌표, 최근접 면적비 또는 station 사이 선형보간으로 실제 결과를 계속하지 않는다.

현재 준비 템플릿은 `config/SPACE_Y_M0_real_input_readiness.json`이고 실제 물성·형상·CEA 매핑 값은 모두 미입력 상태다.

## 5. 검증 상태 분리

| 구분 | 현재 상태 | 의미 |
|---|---|---|
| 자동 단위/통합 테스트 | PASS | 구현된 코드 경로와 합성 산술 확인 |
| N/2N/4N 실행 | PASS | 합성 상수 가스장에 대한 분할 변화 기록 |
| 합성 보존식 | PASS | 계산 경로의 질량·에너지 산술 확인 |
| asymptotic grid regime | NOT_ESTABLISHED | 실제 오차 차수/격자독립성 근거 없음 |
| 실제 IPA 입력 준비 | INPUT_U | 데이터셋·범위·기준상태 미확보 |
| 실제 노즐–CEA 매핑 | INPUT_U | 형상 및 직접 station 대응 근거 미확보 |
| V01–V12 | NOT_RUN | 실제 물리 검증 상태는 변경하지 않음 |
